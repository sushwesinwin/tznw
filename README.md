# Thazin Nwe Win Portfolio

Portfolio and booking website for Thazin Nwe Win, a television presenter, host, MC, and actress based in Yangon, Myanmar.

The site includes a hero section, biography, television program highlights, photo gallery, booking call-to-action, social links, and booking guidelines.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- GSAP, Motion, and OGL for animation/visual effects
- Lucide React icons

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## Scripts

```bash
npm run dev      # Start local development server
npm run build    # Build for production
npm run start    # Start production server
npm run lint     # Run ESLint
```

## Project Structure

```text
app/                     Next.js app routes and global layout
components/              Shared UI and page sections
components/pages/        Homepage sections
lib/                     Constants, photo data, and utilities
public/                  Static images and assets
```
